Everything in the 'figure1_files/setup_with_person_on_photo' directory is 
related to the (edited) setup figure where there is a person on the photo. This is a different figure (.jpg) 
from the one where there is no person on the photo.

The files are as follows:
- `setup2_adapted.jpg`: edited jpg of the setup with drawn walking path on the photo
- `setup2_adapted.photoshop.pdf`: Photoshop file of the edited jpg of the setup with layers
- `setup2_adapted_without_walkingpath.jpg`: edited jpg of the setup without drawn walking path on the photo
- `setup_slide.pdf`: slide with the edited setup figure with drawn walking path, next to floor plan; in pdf format
- `setup_slide.pptx`: PowerPoint slide with the edited setup figure with drawn walking path, next to floor plan
- `setup_slide_without_walkingpath.pdf`: slide with the edited setup figure without drawn walking path, next to floor plan; in pdf format
- `setup_slide_without_walkingpath.pptx`: PowerPoint slide with the edited setup figure without drawn walking path, next to floor plan
