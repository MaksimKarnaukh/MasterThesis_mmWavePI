This `_misc` directory contains several photos and diagrams related to the project, but these were not necessarily all used in the paper.

For the figures used in the paper, refer to the `paper_figures_original` directory for 
the figures in png or jpg format, or the `paper_figures_in_pdf` directory for the 
figures in (converted) pdf format. The paper has a total of 13 figures (excluding the tables of course).
